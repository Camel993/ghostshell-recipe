📝 Lépések — GFN sessionben, felülről lefelé

1. → GFN app/web → Physical kiválasztása (Priority / Ultimate kell — Free és Alliance Partner NEM megy)
2. → Steam-bejelentkezés a sessionben a saját fiókoddal (a Trove jogosultság onnan jön)
3. → Ha Install-t látsz Play helyett: Steam → Library → Trove → Install (pár perc). A GFN minden sessionben tiszta gép, ezért lehet, hogy újra kell.
4. → Steam Library → jobb klikk Trove → Properties → General → „Keep game saves in the Steam Cloud for Trove” pipa KI
Nélküle a Steam visszaírja az eredeti fájlt a swap után → „semmi nem történik”, sima Trove indul.
5. → Steam bal fönt Store → jobb fönt a felhasználóneved → Game library → bármelyik játék oldala → „Open website” → jobb fönt ⋮ → Új lap
Ez a Steam beépített CEF böngészője — a Save As CSAK ebből jön fel. Chrome-ból NEM működik.
6. → A CEF böngésző címsorába illeszd be a PATCH URL-t (1. mező) → Enter → a mentési ablak már GlyphClient.exe névvel nyílik, gépelés nélkül
Ha a böngésző blokkolja: ⋮ → Keep → Keep anyway.
7. → Save As → a „File name” mezőbe másold be a teljes CÉL ÚTVONALAT (2. mező) → Save as type: .exe → Save → „Replace the file?” → Yes
A teljes útvonal beírása felülírja a nevet ÉS a mappát is — ezért elég egy bemásolás.
8. → Steam Library → Trove → Play → ha jön a „fájlok nem egyeznek” / „Steam Cloud Out-of-Date” figyelmeztetés → Play anyway
Ez a figyelmeztetés JEL, hogy a swap éles.
9. → Várj 30–90 másodpercet → megjelenik a fekete hátterű Windows desktop a Zxplorer shell-lel (taskbar, start menü, asztali ikonok)
Ellenőrzés — a felugró ablakban vagy a desktop „GhostShell Log” ikonon az ELSŐ sor:
GhostShell v7.43-2026.09.20 starting.
A verziószám nő, ahogy a build frissül — az URL nem változik.
Ha v5-öt vagy wallpaper.jpg-t látsz: régi URL-ből mentettél (a ghostshell.pages.dev halott, koponyás) → 6–7. pont újra a helyes URL-lel.
9b. → Egyszeri, örök lépés (opcionális, de ajánlott): Steam → Trove → Properties → Installed Files → Move install folder… → I:\user\SteamShadow — utána egyszer megismétled a 6–7. pontot az I:\user\SteamShadow\steamapps\common\Trove\GlyphClient.exe célúttal.
Ettől kezdve a swap túléli a sessiont — legközelebb csak Play. A napló bizonyítja: Swap persistence: PERMANENT. Ha SESSION-ONLY áll, a játék a C:-n van (a GFN session-önként törli).

⌨️ Billentyűkombók a sessionben (v7.42 — SalsaNOW-paritás, AutoHotkey appváltó)

A GFN-kliens és a hiányzó natív explorer shell miatt a Windows-gombok nem élnek; a GhostShell ezeket saját, auditálható kódban pótolja (a salsa CtrlTab/CtrlF4/ToggleDesktop/WindowsMenuToggle AHK-jainak megfelelője). Az appváltó (Alt+Tab / Ctrl+Tab) v7.42-től a hivatalos, nyílt forrású AutoHotkey v2-ben fut — a runtime a saját tükrünkről jön (admin nélkül), a script pedig a repóban olvasható: app/ahk/ghostshell-hotkeys.ahk.

  • Bónusz, ami megmaradt: Ctrl + Alt + T = asztal, Ctrl + Alt + M = start menü (akkor is működnek, ha a kliens a Win-billentyűt elnyeli).
  • Ha a gombok nem jutnak át: az asztali „Next Window” ikon (v7.37) egérrel vált ablakot.
  • A Ctrl + F4 az asztalt/shell ablakot előtérben szándékosan nem zárja be (fekete session lenne) — ilyenkor csak egy sor kerül a naplóba.
  • Ha a váltás „nem csinál semmit”: a napló minden kísérletet leír — Switch [Alt+Tab via LL hook] / [Ctrl+Tab hotkey]: 'honnan' -> 'hova' | foreground OK vagy FAILED, illetve NO candidate windows. Ha egyáltalán nincs Switch-sor, a kliens nyeli el a gombot (kliens-oldali megoldás kell).
  • AutoHotkey appváltó (v7.42): a ghost.log-ban az AHK: AutoHotkey v2 running ... sor jelzi, hogy a váltó tényleg AHK-ban fut; a részletes naplója I:\GhostShell\GhostShell Logs\ahk-hotkeys.log (minden váltás + poll telemetry + 60 mp-enkénti heartbeat). Ha a naplóban nincs egyetlen váltás-sor sem gombnyomásra, akkor a gomb el sem ér a VM-ig — azt csak a GFN-kliens oldalán lehet orvosolni.
  • v7.43 — a diagnózis egy kattintás: a „GhostShell Hotkeys” asztali ikon fájlja egy LIVE STATUS blokkot is mutat: build-verzió, payload root, a háttérkép read-back eredménye (kiderül, ha a shell visszafestette a sajátját), a hotkey-tulajdonlás, az AutoHotkey állapota, és mindkét napló utolsó 12 sora. A Tab edge #n (Alt=… Ctrl=… Shift=…) sor mondja meg, hogy a gomb eljut-e a VM-ig, és hogy a módosítóbillentyű rendben van-e.
